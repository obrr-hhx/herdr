# 本地输入与会话历史

在已识别的 Claude Code 窗格中按 **F6**，或从 Herdr 全局菜单选择 **local chat**。
输入框、历史滚动和编辑均在本地处理，远程 Claude 进程保持运行。更新客户端后
分离并重新打开即可加载新版本，不必重启已有远程服务器。

- **Enter** 提交整条消息；**Ctrl+J** 换行。Shift+Enter、Alt+Enter 是否可用取决于终端。
- 滚轮、**PageUp/PageDown** 阅读本地历史；**Ctrl+Home/End** 跳到已加载历史的开头或最新位置。
  在开头继续向上会按需加载更早的会话记录，加载时显示 **LOADING**。
- 向上阅读时保持当前画面，新回复暂存；回到底部或 Ctrl+End 后恢复跟随。
- 点击输入文本定位光标；长草稿自动增高。Herdr 前缀键仍可用于分屏、切换和分离。
- **Ctrl+Y** 复制当前已加载的历史文本。**Esc/F6** 返回原终端，处理权限确认、斜杠补全、
  图片和 Ctrl+C 中断；草稿保留。

历史从当前 Claude 进程保存的会话文件读取，包含客户端打开之前已经保存的对话。
来源绑定当前机器、窗格和进程会话，不按“项目里最新的文件”猜测，因此切换窗格不会
混入另一段对话。诊断用 API 请求/响应副本、内部上下文和子代理日志不作为主对话展示。
用户消息、Claude 回复、代码、工具结果和错误分别使用主题颜色。这是结构化对话视图，
不是原终端 ANSI 外观的逐像素复制。

历史读取在后台进行，仅活动窗格轮询，通常每秒最多发起一次；文件未变化时不重新传输
内容。每页最多扫描 2 MiB 日志并返回 1 MiB 文本，本地窗口最多保留 8 MiB 或 10,000 个
内容块。超过窗口后仍可继续向前翻页。单个工具结果最多展示 64 KiB，较大的内容块会
明确标注截断；图片显示占位，原图在原终端查看。草稿最多 64 KiB。

尚未保存的输出单独出现在 **Live terminal** 小区域，不并入历史；向上阅读时隐藏该区域，
避免打断阅读。Claude 需要处理确认时显示 **Needs attention · Esc terminal**。
若会话历史暂不可用，会明确提示，并保留原终端入口；备用的屏幕缓存最多 2,000 行、1 MiB，
不会冒充完整会话。客户端草稿和缓存仅存在内存，不另写一份对话文件。

历史提供器使用宿主机上的 Python 3.9+ 标准库，通过 Herdr 公共只读 API 找到实际 Claude
进程，并验证其会话元数据及进程启动身份。当前已验证 Claude Code 2.1.311 的会话格式；
不支持的格式会报历史不可用。SSH 读取复用现有目标、身份和严格主机密钥检查，不安装
远程依赖或重启服务器。也可单独读取：

```sh
herdr --session NAME agent history PANE_ID --ssh-target SSH_TARGET
herdr --session NAME agent history PANE_ID --ssh-target SSH_TARGET --before BYTE_OFFSET
```

提交绑定 endpoint、服务器启动身份和窗格。未确认的提交会恢复已提交文本及之后的新
草稿，绝不自动重发；先 Esc 核实原终端，再 Ctrl+R 明确允许手动重试。提交确认不代表
Claude 已完成回复。同一客户端只保留一个草稿目标，换目标前需发送或清空原草稿。

可选的 `scripts/local_chat_ssh_e2e.py` 检查真实 PTY/SSH/Claude 的输入、尺寸、滚轮、
分屏与放大还原；`scripts/local_chat_history_e2e.py` 进一步检查客户端启动前的早期消息、
超过 2,000 行的保存内容、主题颜色、阅读期间的新回复和客户端重开恢复。目标必须是
独立 `local-chat-e2e-*` 或 `local-chat-history-e2e-*` 测试会话。脚本保存真实终端单元格的
PNG/文本和 JSON 结果；运行 `--help` 查看依赖和参数。
