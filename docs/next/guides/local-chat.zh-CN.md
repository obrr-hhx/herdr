# 本地输入与阅读缓存

在已识别的 Claude Code 窗格中按 **F6**，或从 Herdr 全局菜单选择
**local chat / cached reader**。这是可选的本地视图，远程 Claude 进程和终端保持运行。
安装后分离并重新打开 Herdr 客户端即可使用，无需重启已有服务器。使用阅读和提交功能的目标服务器也需要支持 `pane.read` 和
`agent.prompt` 客户端能力；旧版运行实例可继续使用原终端，新版本可在独立命名会话中试用。

- 打字、中文输入、粘贴、删除、移动光标和多行编辑均在本地完成。Enter
  通过现有 `agent.prompt` 接口提交整条消息；Ctrl+J、Shift+Enter 或 Alt+Enter
  换行。组合 Enter 是否可用取决于终端。
- 滚轮、PageUp/PageDown、Ctrl+Home/End 浏览本地缓存，不等待服务器。
  Ctrl+Y 复制全部缓存文本。
- 向上阅读时固定当前快照，新输出暂存，回到底部或按 Ctrl+End 后恢复跟随。
- Esc 或 F6 返回原终端，处理权限确认、交互问题、斜杠命令补全、图片粘贴和
  Ctrl+C 中断；本地草稿会保留。每个客户端保留一个草稿目标，使用另一窗格前
  先发送或清空当前草稿。

缓存来自真实终端文本，不拼接屏幕截图，也不声称是完整的聊天记录。最多读取
2,000 行终端保留的历史，UTF-8 文本上限 1 MiB。内容有变化时最多每秒刷新两次，
同一时间只有一个读取请求。若应用使用备用屏幕、未保留历史，则无法恢复已经
丢弃的内容。缓存为纯文本，颜色和图片仍在原终端查看。

草稿最多 64 KiB，仅保存在当前客户端内存中，不落盘。远程操作绑定机器、服务器
启动身份和窗格。发送未确认时会恢复已提交文本，并保留之后编辑的新草稿，绝不
自动重发。先切回原终端核实，再按 Ctrl+R 明确允许手动重试，或在服务器重启后
重新绑定草稿。提交确认不代表 Claude 已完成回复。
